## Claude in Chrome

Each Claude in Chrome session makes its own "Claude" tab group. Chrome closes a group when its last tab closes. Groups that stay open collect in the tab bar. Chrome still keeps a saved chip for each closed group in the bookmarks bar. The tools can't delete that chip, so the user deletes it by hand.

- Work in the empty tab that `tabs_context_mcp` with `createIfEmpty` opens. Open a second tab with `tabs_create_mcp` only when the task needs two pages at once.
- When the browser work is done, call `tabs_context_mcp`, then close every tab in the group with `tabs_close_mcp`. Include the empty tab. Do this before the reply that ends the turn, even when the task failed or the user stopped it.
- Keep a tab open only when the user needs it, for example to sign in, solve a CAPTCHA or check a result. Say in the reply which tab stays open and why. Close it in the next turn, after the user says they're done with it.
- Close only tabs in this session's group. Never close the user's own tabs or another session's group.
- A subagent that uses the browser must close its own tabs before it reports back. Put this rule in its prompt.
