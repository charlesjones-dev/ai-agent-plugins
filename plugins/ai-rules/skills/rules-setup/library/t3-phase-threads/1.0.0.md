## T3 Code phase threads

These rules apply in a project that works in phases, in a session that has T3 Code's tools.

- When a phase is finished, don't end the reply as if the thread's work were finished. Ask whether to start a new T3 thread for the next phase. Name that phase and what it depends on.
- Start the thread only after the user says yes. Launch it with `t3_thread_launch`. The repo's own rules give the thread's prompt, such as `/start-phase <next phase>`.
