## T3 Code phase threads

These rules apply in a project that works in phases, in a session that has T3 Code's tools.

- The approved phase plan covers the phase's commit and the start of the next phase. Don't ask for either.
- When a phase is finished and its checks pass, commit it as the repo's rules say. Then start a new T3 thread for the next phase with `t3_thread_launch`. Do this only when the next phase's dependencies are done and no step from this phase still waits on the user. The repo's own rules give the thread's prompt, such as `/start-phase <next phase>`. Give the new thread's link in the reply.
- Ask first only in these cases: a check failed, the next phase depends on work that isn't done, or the user asked to pause between phases. Name the next phase and what it waits on.
